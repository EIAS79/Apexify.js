# Apexify.js visual identity

Aligned with the [Frame homepage](https://apexifyjs.vercel.app/) using near-black (#111111), acid lime (#D5FF5F), off-white (#F2F2EF), and restrained violet reflections.

| Asset | Purpose |
| --- | --- |
| `apexify-logo.avif` | Transparent horizontal logo/wordmark |
| `apexify-npm-banner.jpg` | npm and GitHub README banner |
| `apexify-icon.avif` | High-resolution square brand/app icon |
| `apexify-favicon.png` | 48 × 48 favicon fallback |
| `../Apex-Banner.png` | Updated legacy PNG banner compatibility path |

Images are visual brand assets only; they do not change the public Apexify.js API. The deployed website uses matching assets from `EIAS79/Apexify.js-Documentation`.
